# АвтоЭксперт 05

Мобильное приложение для проверки автомобилей с пробегом перед покупкой.

## Скачать приложение

Последняя версия всегда доступна здесь:

**[⬇ Скачать AvtoExpert.apk](https://github.com/dairsadru/avtoexpert05/releases/latest/download/AvtoExpert.apk)**

### Как установить

1. Скачайте файл `AvtoExpert.apk` на телефон.
2. Откройте его через «Файлы» или «Загрузки».
3. Разрешите установку из этого источника, если Android попросит.
4. Нажмите **Установить**.

> Приложение распространяется напрямую, вне Google Play, поэтому Android предупредит
> об установке из неизвестного источника — это нормально для такой раздачи.

## Возможности

- Справочник автомобилей: марка → модель → поколение с характеристиками, работает офлайн
- Чек-лист осмотра: 10 разделов, ~70 пунктов со статусами «Норма / Внимание / Дефект» и комментариями
- Кузовная схема (карта ЛКП) — отметка состояния окраски по элементам на чертеже
- Фирменный PDF-отчёт с данными компании и эксперта, отправка в WhatsApp и другие приложения
- Отдельный вход для каждого автоэксперта
- Обновление приложения прямо из приложения

## Обновления

Приложение проверяет обновления по файлу [`update.json`](update.json) в этом репозитории:

```json
{
  "versionCode": 1,
  "versionName": "1.0",
  "apkUrl": "https://github.com/dairsadru/avtoexpert05/releases/download/v1.0/AvtoExpert.apk",
  "changelog": "Что нового",
  "mandatory": false
}
```

Приложение сравнивает `versionCode` с установленной сборкой. Если в файле число больше —
предлагает обновиться, скачивает APK и открывает установщик Android.

Адрес манифеста прописан в приложении по умолчанию и меняется в разделе
**Настройки → Обновления**.

### Как выпустить новую версию

1. В `app/build.gradle.kts` увеличьте `versionCode` (например, 1 → 2) и `versionName` («1.0» → «1.1»).
2. Соберите APK: `./gradlew assembleDebug`
3. Создайте релиз и приложите APK под именем `AvtoExpert.apk`:

```bash
gh release create v1.1 app/build/outputs/apk/debug/app-debug.apk#AvtoExpert.apk --title "Версия 1.1" --notes "Что нового"
```

4. Обновите `update.json` в этом репозитории: новые `versionCode`, `versionName`,
   `apkUrl` (на новый тег) и `changelog`.

После этого у всех пользователей в приложении появится предложение обновиться.
